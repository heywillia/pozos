🛠️ Reparación de datos

Vuelve a calcular municipio, provincia y barrio de todos los reportes con la misma lógica que usa la app (ubicacion.js): municipio y provincia de la API Georef oficial (IGN/INDEC), barrio de OpenStreetMap solo si coincide con el partido oficial. Nunca toca estado, votos ni fechas. Si una API no responde, ese dato queda como estaba.

Primero corré Simular: muestra qué cambiaría sin guardar nada. Tarda ~1,5 s por reporte (respeta el límite de 1 consulta por segundo de Nominatim): dejá la pestaña abierta.

Esta página no se publica en Vercel (ver .vercelignore). Para usarla, desde la carpeta del repo: python3 -m http.server 8000 y abrir http://localhost:8000/herramientas/reparar.html.
